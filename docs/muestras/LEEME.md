# Muestras

Imágenes de referencia para mostrar a la persona cómo se ve cada recurso. Las de formatos son composiciones de ejemplo con figuras neutras: muestran la estructura, no el estilo final (que siempre sale con la marca de cada persona).

| Archivo | Qué muestra |
|---|---|
| `03-pantalla-dividida.png` | Formato 3: recurso arriba, persona abajo, texto sobre la unión |
| `05-tarjetas-flotantes.png` | Formato 5: captura flotante sobre el video |
| `41-tablero.png` | Formato 41: tablero con proceso de 3 pasos |
| `43-enfasis.png` | Formato 43: frase de contexto chica + palabra clave grande |
| `45-pov.jpg` | Formato 45: título de apertura fijo |
| `iconos.png` | Los 18 íconos del motor (`kit/iconos.py`) |
| `carrusel-ejemplo.jpg` | Un carrusel hecho con `kit/carrusel.py` y una marca de ejemplo |

Para ver los recursos sobre el video de la persona, usar `python3 -m kit.muestrario` (ver `docs/opciones-de-edicion.md`).
