# Para Claude

Este repositorio es un sistema para editar reels y diseñar carruseles con la marca de cada persona.

1. Si te pidieron "instalar esto" o la persona subió material sin explicar nada, leé primero `docs/arranque.md`: ahí está el modo guiado paso a paso y el modo "hacelo vos".
2. Para trabajar, seguí `SKILL.md`.
3. Hablale a la persona en simple: ella no tiene por qué saber qué es un repositorio, un archivo JSON o un render.
